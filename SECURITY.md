# Security policy

Only the latest preview release is maintained. Ankunft currently uses an early
release process; do not assume independent security auditing or encrypted cache
storage. See the README for the storage and permission model.

Please report vulnerabilities privately using GitHub's **Report a vulnerability**
button on this repository's Security page. Include a minimal reproduction with
synthetic data. Never send a real Parcel API key or personal delivery data.

Use public issues for ordinary bugs that do not expose sensitive information.
